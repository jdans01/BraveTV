# BraveTV Browser

Navegador para Android TV con bloqueador de anuncios integrado.  
Bloquea anuncios de YouTube, Google Ads, trackers y más.

## Funciones
- Bloqueo de anuncios de YouTube (pre-roll, mid-roll, banners)
- Skip automático de anuncios que logran pasar
- Interfaz optimizada para control remoto
- Compatible con Hisense, TCL, Sony, Philips y cualquier Android TV
- Requiere Android 5.0+ (API 21)

## Compilar el APK

GitHub Actions compila el APK automáticamente en cada push.  
Ve a **Actions → Build BraveTV APK → Artifacts** para descargarlo.
